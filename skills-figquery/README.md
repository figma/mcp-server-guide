# skills-figquery

The figquery variant of the skills. Cursor is the only client that reads it:
[`.cursor-plugin/plugin.json`](../.cursor-plugin/plugin.json) points its `skills` field
here, which overrides Cursor's default `skills/` discovery.

Every other client keeps reading [`skills/`](../skills):

- Claude Code, via `.claude-plugin/plugin.json` (no `skills` field, so it defaults to `skills/`)
- GitHub Copilot, via the `.github/plugin` entry in `github/awesome-copilot`
- Gemini CLI, via `gemini-extension.json`, which declares no skills at all

The two trees hold the same 14 skills under the same names, so slash commands and
skill descriptions are identical in both. Only the guidance content differs.

Contents are generated by the `mcp-sync-skills` skill in `figma/figma`. `skills/`
comes from the `figma-plugin` plugin; this directory comes from
`figma-plugin-fig-query`, limited to that plugin's `sync_allowlist.json`. Skills the
fig-query allowlist does not cover (`figma-implement-motion`, `figma-use-motion`)
are copied from `skills/` unchanged. Do not hand-edit either tree.
